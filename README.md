🎬 YouTube UI Clone (Frontend Project)

This project is a simple **YouTube User Interface Clone** built using HTML and CSS. It replicates the basic layout of YouTube including the header, sidebar, and video grid.

🚀 Features

- Responsive Header with:
  - YouTube logo
  - Search bar
  - User profile icon
- Sidebar Navigation:
  - Home
  - Shorts
  - Subscriptions
  - Library
- Video Grid Layout:
  - Thumbnail images
  - Video titles
  - Channel names
  - Views and upload time

🛠️ Technologies Used

- HTML5
- CSS3

📸 Preview

The UI mimics a basic YouTube layout with a clean and structured design.
